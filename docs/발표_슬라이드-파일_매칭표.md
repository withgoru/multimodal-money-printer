## 발표 전에 정할 것

1. **비교 문서의 A/B/C 이름표가 서로 다릅니다.** Claude 문서는 A가 박수정, C가 최우영입니다. Gemini 문서는 A가 최우영, C가 박수정입니다. ChatGPT 문서는 이니셜(cwy, psj, wsi)을 씁니다. 슬라이드에서는 사람 이름으로 통일했습니다.
2. **통합 기획서의 `[cite: 1, 2, 3]` 표시는 정리해야 합니다.** 번호가 어느 기획서인지 표기가 없습니다. 문맥으로는 1이 최우영, 2가 원성일, 3이 박수정으로 읽히지만 확인이 필요합니다.
3. **공지의 필수 범위인 '스킬 등 에이전트 형태로 완성'을 채운 것은 원성일과 박수정입니다.** 최우영의 설계와 통합 기획서는 아직 문서 상태입니다.
4. **6~11번 슬라이드는 다른 두 분의 문서를 읽고 정리한 것입니다.** 발표자 본인이 확인해야 합니다.
