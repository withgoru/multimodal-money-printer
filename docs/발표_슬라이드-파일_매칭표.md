## 발표 전에 정할 것

1. **비교 문서의 A/B/C 이름표 통일:** Claude 문서는 A=박수정·C=최우영, Gemini 문서는 A=최우영·C=박수정, ChatGPT 문서는 이니셜(cwy, psj, wsi)을 씁니다. 슬라이드에서는 전 슬라이드에서 **`박수정 · 원성일 · 최우영`** 순으로 통일했습니다.
2. **통합 기획서의 `[cite: 1, 2, 3]` 대조 완료:** 본문 대조 결과 **1=최우영, 2=원성일, 3=박수정**임을 확인했습니다. 슬라이드에는 기여자 이름을 직접 표기했고, 향후 통합 기획서 본문 정리 시 반영하면 됩니다.
3. **에이전트·스킬 형태 현황:** 박수정은 `lesson-author` 5모듈 스킬과 Studio 연동, 원성일은 4개 스킬(`v2.9.0`)과 다중 검토 에이전트, 최우영은 `AGENTS.md`와 Slidev 환경을 구축했습니다. 통합 기획서는 아직 문서 상태이며, `AGENTS.md`·Slidev를 최우영 파트 성과에 포함할지 팀에서 확정합니다.
4. **본인 확인 및 발표 운영 사항:** 5~10번 슬라이드는 박수정·원성일 문서를 정리한 내용이므로 본인 확인이 필요합니다. `M1-1-T`(이론 180분, HTML·PDF 14쪽) 포함 여부, 원성일 HTML 산출물 라이브 시연 여부, 1인 발표 대 3인 릴레이 발표 분담을 정하면 됩니다.
