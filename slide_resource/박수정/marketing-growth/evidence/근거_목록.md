# 멀티모달 AI 데이터 기반그로스 마케팅 · 교안 근거 수집

수집일: 2026-11-18

상태: **강사 검토용 근거 목록**. 교안·차시 시수·실습 데이터·평가 기준을 확정하거나 Instructor Studio 과정 데이터에 적용하지 않았다.

## 수집 범위와 기준

이 문서는 [채택된 7개 커리큘럼 항목](../NCS_선정_기록.md#1-채택한-커리큘럼)을 기준으로 **새로 수집한 외부 자료 19건**을 기록한다. 유형은 연구 논문·학술 논평 7건(P01~P07), 공식 제품 문서·공개 데이터 안내 12건(D01~D12)이다. 기존의 `marketing-causal-analysis-draft/`는 사용자 요청에 따라 삭제했고, 그 폴더의 시강·32시간 과정안·근거 2건은 이 목록으로 이전하지 않았다.

원문 위치와 한계를 확인한 내용만 교안 근거로 사용한다. 아래 `수업 활용`은 **설계 제안**이며, 논문 저자가 해당 교안을 권고했다는 뜻이 아니다. 원문 PDF 3건은 [sources/](./sources)에 보관했다. 나머지는 원문 링크를 기록했다.

이 근거를 바탕으로 작성한 [근거 중심 학습서 원고](./근거_중심_학습서.md)는 7개 주제의 개념·해석·가상 계산과 각 장의 확인 질문을 담은 검토용 초안이다. 부록 B에는 P01~P07 및 D01~D12 **19건 전부의 사용 위치·원문 링크·해석 한계**를 기록했다. 강의안이나 슬라이드는 아니다.

학습서 원고에 [112시간 대응 워크북](./112h-workbook/112시간_실습_워크북.md)을 더했다. 유일하게 유지하는 [통합 PDF](../pdf/marketing-growth-112h-study-package-2026-11-18.pdf)는 학습서, 23개 항목 워크북과 데이터 사전을 엮고 가상 원본 14개를 첨부한다. **112시간은 편성 초안의 합계이며 실수업 시간으로 검증된 값은 아니다.**

통합 PDF에는 가상 광고 이미지·문구·합성 음성·정지 클립·성과·실험·예측 데이터와 공식 GA4 공개 자료의 접근 경로를 구분해 담았다. 재사용 가능한 원본은 [가상 데이터 원본 목록](./multimodal-assets/README.md)과 [112시간 워크북 데이터 설명](./112h-workbook/가상_데이터_설명.md)에 기록했다.

## 강사 검토 전 확인 항목

1. **실습 데이터:** D07은 퍼널·전환 분석에 사용 가능하지만 광고비와 A/B 배정이 없어 광고 증분 효과·ROAS 실습에는 별도 교육용 데이터가 필요하다. 새로 만든 데이터는 **가상 자료**라고 표시한다.
2. **AI 자동화:** D04는 계산식 생성 보조의 공식 근거다. 멀티모달 AI가 광고 실험의 무작위 배정·유의성 판단을 자동으로 보증한다는 근거는 수집되지 않았다.
3. **도구 접근:** GA4 속성, 광고 계정, Looker Studio/Data Studio 권한, Gemini Pro 여부와 BigQuery 비용·접근 조건을 확인해야 실제 실습 절차를 쓸 수 있다.
4. **연구와 학습 수준:** P03·P04의 시계열 추론과 예산 시뮬레이션은 고급 주제다. 학습 대상·선수지식·시수가 정해지기 전에는 개념 설명과 심화 실습의 경계를 확정하지 않는다.
5. **NCS 연결:** [마케팅 성과 관리·고객데이터 분석 선택 근거](../NCS_선정_기록.md#2-선택한-ncs-능력단위)를 별도로 유지한다. NCS 원문이 GA4·AI·A/B 테스트 제품이나 절차를 지정한 것으로 표시하지 않는다.
