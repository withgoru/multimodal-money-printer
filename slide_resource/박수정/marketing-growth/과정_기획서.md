# 멀티모달 AI 데이터 기반그로스 마케팅 과정 기획서

작성일: 2026-11-18<br>
작성자: Codex 초안 · 강사 검토 필요<br>
설계 상태: **검토용 초안**<br>
운영 범위: **112시간 독립 과정**. REF-031의 800시간 과정 중 동명 교과를 시간·내용의 참고 사례로 사용

Instructor Studio에는 이 기획서의 대상·직무·112시간·성취목표 7개를 저장했다. [적용 기록](./LMS_적용_기록_2026-11-18.md)에 교과·목차·자료 결정의 현재 상태를 남겼다. 공식 훈련과정 신청과 실습 환경 확인은 별도다.

## 1. 과정의 목적

| 항목 | 작성 내용 |
|---|---|
| 목표 직무·현장 과업 | **데이터 기반 그로스 마케터·퍼포먼스 마케팅 분석 담당자.** 캠페인 목표와 지표를 정하고, 고객·광고 데이터를 분석하며, 광고 소재와 타기팅 개선 가설을 실험하고, 결과와 불확실성을 설명해 다음 실행·예산안을 제안한다. |
| 훈련 대상·선수지식 | 광고 운영과 기본 데이터 해석을 배우려는 **예비·초급 마케터 및 직무 전환자** 중 디지털 광고 용어, 전환 퍼널, 스프레드시트의 필터·집계에 익숙한 사람을 우선 대상으로 가정한다. GA4·Looker Studio와 AI 도구 경험은 도움이 되지만 필수 자격으로 확정하지 않는다. 선수학습 수준은 개강 전 진단으로 확인한다. |
| 현장 수요·설계 근거 | [REF-031](references/REF-031_멀티모달AI_풀퍼널마케팅.md)의 고용24 공개 과정에는 동명 교과가 **112시간**으로 편성되어 있고 GA4·Looker Studio, 시각화, A/B 테스트, 예측 모델링이 제시된다. 이는 교육과정 사례이며 채용 수요의 정량 근거는 아니다. 실제 기업 데이터·업무 요구는 별도 확인한다. |
| 수료 후 성과 | 동일한 캠페인 사례에 대해 **측정 계획 → 데이터 품질 확인 → GA4 분석·대시보드 → 멀티모달 소재 비교 → A/B 실험 해석 → 예측·시뮬레이션 → 광고 개선안**을 근거와 함께 제시한다. |
| 목표 총 훈련시간 | **112시간 독립 과정(사용자 확정).** REF-031의 동명 교과 시간을 참고했다. 아래 교과별 이론·실기 및 NCS/비 NCS 배분은 강사 검토용 제안이다. |

사용자가 채택한 일곱 주제의 정확한 문구와 순서는 [커리큘럼·NCS 선정 기록](./NCS_선정_기록.md)에 보존한다. 이 문서의 학습 순서는 선수 관계를 고려한 **운영 초안**이며 채택한 주제를 삭제하거나 바꾸지 않는다.

## 5. 프로젝트와 평가

| 항목 | 작성 내용 |
|---|---|
| 현장 과제·프로젝트 주제 | 하나의 가상 또는 사용 허가를 받은 광고 캠페인에서 **다음 집행안을 결정**한다. 같은 사례를 전 구간에서 이어 사용한다. |
| 필수 결과물 | 측정 계획서, 데이터 품질 점검표, GA4 분석 및 Looker Studio 대시보드, 멀티모달 소재 비교·A/B 실험 설계와 결과 해석, 예측·시뮬레이션 기록, 광고 개선 제안서. |
| 능력단위별 평가 | 성과 관리: KPI·원인·개선안의 연결. 고객데이터 분석: 수집·정제 기준, 분석·시각화와 해석. 전략 계획: 측정 가능한 목표와 실행·자원 계획. 각 평가 문항은 원문 수행준거에 다시 연결한다. |
| 비 NCS·통합 평가 | A/B 무작위 배정·표본·불확실성 판단, 도구 결과 재현, AI 해석의 원자료 대조, 예측 가정과 대안 비교를 확인한다. 통계적 유의성만으로 예산 집행을 결정하지 않는다. |
| 실습 환경·예산 | GA4/Looker Studio 접근 권한, 광고 계정·데이터 사용 허가, AI 도구의 키·비용이 **미확정**이다. 없으면 익명화·합성 캠페인 데이터와 미리 준비한 화면·결과로 대체한다. 개인정보와 광고 계정 비밀값은 일반 AI 입력에 넣지 않는다. |

## 6. 시간·출처 검산과 강사 확인 사항

| 확인 항목 | 결과 |
|---|---|
| NCS 이론 + NCS 실기 | **22 + 42 = 64시간(잠정)** |
| 비 NCS 이론 + 비 NCS 실기 | **16 + 32 = 48시간(잠정)** |
| 프로젝트 시간의 중복 계상 여부 | 최종 산출물 제작은 위 실기시간 안에 포함한다. 별도 프로젝트 시간을 더하지 않음 |
| 교과 편성표 합계와 목표 총시간 차이 | **0시간(112시간)** |
| NCS 코드·버전·수준의 제공 PDF 대조 | 완료. 현행 공시·신청 요건 확인은 별도 필요 |
| 고용24 참고 과정의 원문 링크 확인 | [REF-031의 수집 기록](references/REF-031_멀티모달AI_풀퍼널마케팅.md) 참조. 원문은 NCS 미적용 편성 |

### 사용 전에 결정할 것

1. **112시간 독립 과정**으로 운영한다. REF-031의 앞 교과를 선수학습으로 전제하지 않으므로, 필요한 광고·통계·도구 기초의 진단과 보충 방식을 정한다.
2. 학습자의 광고 운영·통계 기초 수준을 확인한다. 선택 단위는 모두 **NCS 수준 5**이므로 기초가 부족하면 사전학습 또는 목표 범위 조정이 필요하다.
3. GA4·Looker Studio·광고 계정 접근, 캠페인 데이터 사용 허가, 유료 AI 도구·광고 예산을 확인한다.
4. A/B 실험에 실제 표본이 있는지, 수업용 가상 결과로 통계 해석을 연습할지 결정한다.
5. 교과 6개와 목차 46개는 [Studio 초안](./LMS_적용_기록_2026-11-18.md)에 저장했다. [실습 23개와 로컬 데모 계획](./실습_데모_설계.md)도 저장했으며, 능력단위별 사전·사후 평가 문항은 후속 단계에서 수행준거에 다시 대조한다.
