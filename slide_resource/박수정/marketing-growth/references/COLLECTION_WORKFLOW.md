# 레퍼런스 수집 절차 기록

원래 KDT 작업 공간의 공용 레퍼런스는 별도 기준으로 33건 수집됐다. 이 공개 저장소에는 이번 마케팅 과정에서 직접 채택하거나 비교한 [REF-031~033](INDEX.md)만 포함한다. [진행 현황](../진행_현황.md)의 AI/AX·마케팅·데이터 분석 교과 동시 확인 기준을 이번 과정의 채택 판정에 사용한다.

새 후보를 조사할 때에는 [고용24 K-디지털 훈련 검색](https://www.work24.go.kr/hr/a/a/1100/trnnCrsInf2.do)에서 과정 상세의 교과편성표를 열고, 과정 ID·회차·기관·수집일·원문 URL·교과명·시간을 기록한다. 제목만으로 판정하지 않고 저장된 REF-031~033의 과정 ID와 교과 내용을 대조한다. 원문 사실, 이번 과정에 대한 해석, 새 설계 제안을 구분한다.

고용24의 모집 상태와 교과편성은 바뀔 수 있다. 기존 문서의 수집일을 현재 상태로 읽지 말고 원문 화면을 다시 확인한다.
