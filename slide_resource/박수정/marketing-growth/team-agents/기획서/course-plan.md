# 멀티모달 AI 그로스 마케팅 강의 기획서

작성일: 2026-11-18 · 원본: [Claude Docs 문서](https://claude.ai/artifact/AthjBpUzn6EGnmsWp9VzbU)

## 수업 목적

마케터를 준비하는 비전공 취업준비생이 AI와 데이터로 광고 성과를 읽고, 근거를 갖춰 개선안과 실험을 제안하도록 돕는 수업입니다. 수강생은 GA4 데모·샘플 데이터와, 팀당 50만원으로 직접 집행한 Meta 광고 데이터로 퍼널 지표를 해석하고 개선안 3개를 냅니다. 멀티모달 AI는 광고 소재의 요소를 해석하고 A/B 테스트용 변형 이미지를 만드는 데 쓰되, AI의 해석은 반드시 데이터와 실험으로 검증합니다. 수강생은 클릭률 기준 A/B 실험을 설계하고 통계적 유의성으로 판정하며, 예측 모델링과 시뮬레이션은 맛보기로만 다룹니다. 결과물은 분석 리포트, 대시보드, 자동화 워크플로우 보고서이고 포트폴리오로 쓸 수 있습니다. 수업은 월수금 10회 80시간의 오프라인 강의이며, 매회 오전은 이론·시연, 오후는 팀(4인) 프로젝트로 진행합니다.

## 대상

대상은 마케터를 준비하는 비전공 취업준비생이며, 수강생의 실제 지식과 경력은 아직 조사하지 않았습니다. 모든 수강생의 경력을 안다고 보지 않고, 수업 전 10분 사전 진단으로 확인합니다. 표시: \[사용자\] = 선생님이 직접 말씀하신 것, \[조사\] = 조사로 확인한 것, \[가정\] = 제가 추정한 것, \[확인필요\] = 수업 전 직접 확인할 것.

## 학습목표

수업이 끝났을 때 수강생이 근거와 이유를 대며 할 수 있어야 하는 일은 다음 세 가지입니다. 목표 문장은 \[무엇을\] \[어떤 근거·조건에서\] \[할 수 있다\] 형태이고, 수행 기준은 제 제안이라 선생님의 합격선으로 조정하시면 됩니다.

1. **진단과 개선안.** 직접 집행한 Meta 광고 데이터와 GA4 데이터를 근거로, 퍼널 단계별 지표(CTR, CPC, 전환율 등)를 해석해 문제 지점을 찾고, 근거와 우선순위를 붙인 개선안 3개를 리포트와 대시보드로 제시할 수 있다.
   - 수행 기준: 각 개선안에 "어떤 지표가 기준선 대비 어떻게 나빠졌고, 왜 그렇게 추정하며, 어떻게 확인할 것인가"가 들어 있고, 데이터가 적어 말할 수 없는 부분을 명시한다.
   - 주 회차: 1\~6
2. **실험 설계와 판정.** 팀 예산(50만원)으로 확보 가능한 표본을 계산한 뒤 그 범위에서 클릭률 A/B 실험을 설계(가설, 대조군, 동시 집행, 수정 금지)하고, 결과를 유의성 검정으로 판정해 "이 데이터로 말할 수 있는 것과 없는 것"을 구분해 설명할 수 있다.
   - 수행 기준: 실험 설계서에 가설, 변수 하나, 필요 표본, 판정 기준이 있고, 판정을 p값의 올바른 의미와 표본 한계와 함께 설명한다.
   - 주 회차: 4\~8
3. **AI 활용과 검증, 반복 체계.** 멀티모달 AI가 내놓은 소재 해석과 변형 소재를 성과 데이터로 검증해 채택 여부를 판단하고, 이를 자동화 워크플로우로 반복 가능한 보고 체계로 만들 수 있다.
   - 수행 기준: AI가 지적한 소재 요소 중 데이터로 확인된 것과 확인되지 않은 것을 구분하고, 워크플로우가 데이터 갱신부터 보고서 생성까지 한 흐름으로 작동하며, 오류가 날 때 사람이 확인하는 단계가 있다.
   - 주 회차: 3\~9

목표에서 일부러 뺀 것: 예측 모델링과 시뮬레이션(맛보기로 정함), SQL(신입 공고에서 우대사항), 전환율 판정과 정교한 퍼널 분석(예산 한계).

## 평가 증거와 루브릭

평가는 결과물이 같은지가 아니라 수강생이 어떤 근거로 왜 그렇게 골랐는지 설명하는지를 봅니다. 시간은 기존 오전·오후 활동 안에서 모으고, 이 표의 예시 답은 모두 제가 만든 가상 답입니다. 실제 수강생 답으로 한 번 시험해 고치세요.

판정 기준(공통): ① 근거: 어떤 데이터(수치)를 봤는가. ② 이유: 그 데이터가 왜 그 판단으로 이어지는가. ③ 한계: 그 판단이 틀릴 수 있는 조건이나 다른 후보는 무엇인가. 세 가지를 모두 갖추면 "이해한 답", 하나라도 빠지면 "보완이 필요한 답"입니다. 다른 지점을 골라도 세 가지가 맞으면 통과입니다. 팀 결과물만으로는 개인 이해를 구분할 수 없으므로 증거마다 개인 서면 답 또는 무작위 구두 질문을 넣습니다.

### 결과물 3종 합격 기준 (제 제안, 조정 가능)

통과 여부는 "완성했는가"가 아니라 근거·이유·한계가 들어 있는지로 봅니다. 두 수준(통과, 보완 필요)만 두고, 보완 필요는 다시 제출합니다. 결과물은 팀 단위라 본인 담당 파트를 적은 개인 기여 기록을 함께 제출합니다(포트폴리오에서 본인 담당 파트를 명시하라는 조언에 근거, 커뮤니티 의견 수준).

| 결과물 | 통과 기준 | 완성·작동 확인 방법 | 제출 시점 |
| --- | --- | --- | --- |
| ① 분석 리포트 | 개선안 3개 각각에 (a) 어떤 지표가 기준선 대비 어떻게 나쁜지 수치, (b) 왜 그렇게 추정하는지, (c) 어떻게 확인할지, (d) 데이터가 적어 말할 수 없는 부분이 들어 있고, 1순위 선택 이유와 제외한 후보의 이유가 있다 | 강사가 항목 체크리스트(개선안 3개 × 위 4요소)로 확인, 증거 1-2 구두 질의와 함께 판단 | 초안 4회차 오후, 최종 6회차 오전 |

월수금 일정의 이유: A/B 광고를 5회차 수요일 오후에 시작해 8회차 수요일 오전에 판정하면 7일간 집행되어 평일과 주말이 포함되고, 6·7회차 대시보드와 자동화가 진행 중인 실제 데이터 위에서 돌아갑니다(제 추론, 연속 진행보다 광고 데이터가 쌓일 시간이 더 길다는 이점). 단점: 금요일에서 월요일 3일 공백, 주말 광고 집행 관리, 주 24시간 수업 피로. 대응: 월요일 오전 30분 복습·데이터 점검, 광고 상한·종료일 설정과 팀별 하루 10분 확인 담당자.

**회차 안 원리 장치(Merrill 점검 반영):** 오전 시작 10분 3문항 회상(활성화), 강사 시범은 생각 소리 내어 말하기와 서로 다른 증례 2\~3종(시연), 오후 팀 프로젝트와 순회 코칭(적용), 마무리 10\~15분 한 줄 성찰(통합), 10회차에 성찰 노트·전이 증례·면접 시연. 평가는 문서 초안 수준이고 실제 수강생 반응과 강사 운영에 따라 달라집니다.

### 1회차 단가 실측과 재계산 절차

표본·예산 수치는 글로벌 평균 단가와 환율 가정에 기대고 있으므로, 기준선 광고의 실제 단가로 다시 계산합니다.

1. 2회차 오전(집행 약 1일 후)과 3회차 오전에 팀별 노출·클릭·지출을 기록합니다.
2. CPM = 지출 ÷ 노출 × 1,000, CTR = 클릭 ÷ 노출로 계산합니다.
3. 그룹당 예상 노출 = (A/B 예산 ÷ 2) ÷ CPM × 1,000. A/B 예산 35만원에 CPM 약 19,600원이면 약 8,900회입니다.
4. 아래 표로 설계 범위를 정합니다. 표의 기준은 기준 CTR 1.0%일 때 제가 계산한 값(유의수준 5%, 검정력 80%)이며, 실측 CTR이 다르면 두 비율 계산 시트로 다시 계산합니다.
5. 5회차 설계서에 실측 단가와 재계산한 표본을 적고, 강사가 팀별로 확인합니다.

| 그룹당 예상 노출 | 설계 범위 |
| --- | --- |
| 7,747회 이상 | 1.0%→1.5% 차이까지 판정 가능 |
| 2,315\~7,747회 | 1.0%→2.0% 같은 큰 차이만 판정, 소재 개념을 뚜렷이 다르게 |
| 2,315회 미만 | 집행 기간 연장, 예비비 투입, 또는 "판정 불가"를 설계서 대조 사례로 운영 |

| 대시보드 | Looker AI 기능 사용 불가 | 범용 AI에 표를 붙여 해석 |
| 자동화 | 도구 계정·권한 문제 | 스프레드시트 수식과 수동 갱신 절차 문서로 대체 |
| 전체 | 네트워크 장애, 강사 계정 하나에 의존 | 핫스폿, 사전 다운로드 자료, API 키 2개 이상 준비 |

가장 먼저 확인할 5가지(막히면 수업 구조가 바뀝니다): ① Model API 가입·지원 국가·약관·키 운영 ② Meta 광고 계정 개설·결제·A/B 테스트 접근 ③ 랜딩의 GA4 속성 소유자·권한·이벤트 설정 ④ 교실 네트워크의 접속 차단 여부 ⑤ 제출 플랫폼과 자동화 도구 선택. 위 다섯 가지를 확인한 뒤 강사가 테스트 계정으로 전체 흐름을 한 번 처음부터 끝까지 리허설하세요.

### 선택 이유

- 병행형 뼈대: 결과물 3종 확보가 필요하고 비전공자는 도구에 먼저 익숙해야 하기 때문.
- 증례 회진(3·4회차): 진단 근거를 말하는 훈련이 평가 기준(근거·이유·한계)과 직접 맞아닿음.
- 사전등록·동료검토(5·8회차): 표본 부족 상태에서 결론을 내리는 위험을 막기 위함.
- 오류 해부(6·8·9회차): AI 결과가 틀릴 수 있다는 사례와 LLM의 시각 권고 한계가 근거.
- 월수금: A/B 집행 7일 확보와 대시보드·자동화를 실제 데이터 위에서 돌리기 위함(제 추론).
- 소재 해석은 Spark로 요소 후보 → SAM으로 면적 측정: SAM이 설명을 못 하고 개념 하나씩만 찾는다는 문서 확인에 근거. 면적이 CTR과 관련된다는 직접 근거는 없으므로 가설 단계로만 사용.

## 점검

시간 총량은 가능하지만, 목표 3의 증거 연결, 결과물 3종의 합격 기준, 문서에 없는 숨은 가정, 세부 시간표가 없는 과밀 회차 5개가 보완 대상이었고, 아래 표는 보완 전 상태입니다. 반영 결과는 마지막의 "조치 반영 현황"에 있습니다. 점검은 이 문서 자체를 기준으로 한 것이고, 실제 수업 운영이나 수강생 반응은 확인하지 못했습니다.

### 1. 목표–증거–활동 대응

| 목표 | 증거 | 활동 | 판정 | 틈 |

### 2. 근거 없는 선택

| 선택 | 근거 상태 | 조치 |
| --- | --- | --- |
| 월수금, A/B 7일 집행 | 제 추론, 근거 없음 | 일정 확정 시 재검토, 첫 기수 후 확인 |

| SAM 박스 면적 비율이 소재 분석에 유의미하다는 점 | 직접 근거 없음(연구는 속성 추출→통계까지만, 면적과 CTR 관련성은 확인 안 됨) | 가설 단계로만 사용(이미 반영) |
| 멀티모달 소재 분석의 현업 활용 정도 | 미확인 | 개념 소개 수준 유지 |

| 신입 취업 관점 | 커뮤니티 의견과 경력 공고 1건 | 신입 공고 원문 확보 시 재확인 |

근거가 있는 선택(공식 문서 확인): GA4 구조와 데모·샘플 한계, SAM·Muse Image·Spark의 API 제약과 가격, Spark→SAM 분업.

### 3. 가정 표시

대상·반 규모·평가 예시 답·시간 배분·미확인 운영 조건은 표시되었습니다. **문서에 없던 숨은 가정**을 여기서 명시합니다.

| 숨은 가정 | 내용 | 영향 |
| --- | --- | --- |
| 환율 | 1달러=1,400원으로 예산을 환산 | 예상 노출·표본 수치가 이에 따라 달라짐 |
| 단가 | CPM 약 $14, 클릭률 1.5% (글로벌 평균, 한국 지표 아님) | A/B 판정 가능한 최소 차이가 바뀜 |
| 표본 계산 방식 | 노출이 서로 독립이라는 표준 근사식(실제 광고는 같은 사람이 여러 번 봄) | 계산이 근사치임을 수업에서 밝힐 것 |
| 강사 인원 | 강사 1명이 오후 순회 코칭을 한다고 가정(문서에 강사 수 없음) | 팀 5개 이상이면 팀당 코칭 시간 부족 |
| 랜딩의 GA4 태그 | 랜딩에 GA4와 핵심 이벤트가 이미 설치되어 있다는 가정(준비됨 표현에서 추정) | 아니면 2회차 실습이 무너짐 |

### 4. 시간 안에 가능한가

**총량은 가능하지만 회차 단위로는 과밀 위험이 큽니다:**

- **1회차:** 완성 리포트 예시, 퍼널·지표 이론, 팀 구성, 계정·GA4·랜딩 점검, 기준선 광고 집행이 한 날에 모이고, 계정 문제가 생기면 오후가 무너집니다.
- **4회차(가장 위험):** 개선안 이론, Spark→SAM 측정, Muse 변형, 증례 회진(오전)과 개선안 리포트, 소재 변형 제작, SAM 재측정(오후)이 한 회차에 있습니다.
- **5회차:** 통계 기초·동전 체험·표본 계산, 설계서·동료 검토 60분, A/B 광고 세팅이 겹칩니다. A/B 시작이 늦어지면 8회차 판정의 7일 집행이 무너집니다.
- **8회차:** 판정 이론, 오류 해부, 판정 변형 문제, 설계서 대조, 증거 2-2·3-1 수집이 모입니다.
- **10회차:** 포트폴리오 작성법, AI 표시 점검, 성찰 노트, 전이 증례, 면접 시연, 최종 발표와 피드백이 한 회차에 모입니다.
- **6·7회차:** 대시보드·자동화 도구가 아직 정해지지 않아 시간을 추정할 수 없습니다.

회차별 분 단위 시간표는 아직 없습니다. 4·5회차는 개선안 리포트 마감을 6회차 오전으로 미루는 방안(1-2 구두 질의는 초안으로)을 검토해 볼 만합니다.

### 우선 조치 (제 제안)

1. 결과물 3종(리포트·대시보드·자동화 보고서)의 합격 기준을 작성합니다. 자동화가 작동한다는 것을 확인하는 방법도 정합니다.
2. 목표 3의 도구 활동과 증거를 연결합니다. 측정값과 성과 비교 활동을 추가하고, 3-1에 측정 결과를 포함시킵지 결정합니다.
3. 숨은 가정 다섯 가지를 본문의 해당 섹션에도 반영합니다.
4. 과밀 회차(1·4·5·8·10)의 분 단위 시간표를 만듭니다.
5. 통합 활동(성찰 노트·전이 증례·면접 시연)을 평가에 반영할지 정합니다.
6. 1회차 단가 실측 후 예산 배분과 표본을 재계산하고, 설계 판단으로만 정한 선택은 첫 기수 후 검증합니다.
