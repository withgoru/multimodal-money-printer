# 1번 에이전트 · 제안 분석과 학습 요구

**사용 시점:** 팀 회의에서 세부 주제·학습자·시강 조건을 정한 뒤. 회의 준비에 필요한 제안 분석과 과정 편성은 이미 [과정 기획서](../../과정_기획서.md), [교과·차시 편성](../../교과_차시_편성.md), [공유 브리프](../공유_브리프.md)에 있다.

아래는 **팀원이 에이전트에 전달할 재현용 지시문**이다. 실제 실행 명령이나 완료 기록이 아니다. 실행 증거는 `marketing-growth/team-agents/결과/`에 생성한 파일과 사람의 검토 기록으로 남긴다.

## 전달할 지시문

```text
저장소 루트에서 작업해. 먼저 .Codex/constitution.md,
marketing-growth/AGENTS.md, marketing-growth/team-agents/공유_브리프.md를 읽어.

너는 팀 과제의 1번 담당이다. 고용24 REF-031의 원문 사실과 이 프로젝트가
새로 설계한 112시간 독립 과정을 구분해, 팀이 선택한 시강 주제의 학습 요구를 정리해.

입력:
- output/course/curriculum-references/REF-031_멀티모달AI_풀퍼널마케팅.md
- marketing-growth/과정_기획서.md
- marketing-growth/NCS_선정_기록.md
- marketing-growth/교과_차시_편성.md
- marketing-growth/evidence/근거_목록.md
- marketing-growth/team-agents/공유_브리프.md

출력: marketing-growth/team-agents/결과/01_근거와_목표.md 한 파일.

반드시 담을 내용:
1. REF-031 전체 800시간과 동명 교과 112시간, 이번 독립 과정 112시간의 구분.
2. 예상 수강생의 과업·문제·선수지식. 실제 조사 결과와 설계 가정을 분리.
3. 문제에서 도출한 학습 요구, 팀이 정한 한 차시의 관찰 가능한 행동 목표와 확인 증거.
4. 해당 목표가 과정의 어느 교과·목차에 연결되는지와 원문 위치.
5. 확인한 것 / 가정 / 남은 질문 / 2번에게 넘길 것.

팀이 세부 주제·시간을 아직 정하지 않았다면 확정 목표를 만들어 내지 말고
미결정 사항으로 남겨. NCS 수행준거는 실제 원문 쪽을 확인한 경우에만 인용해.
다른 담당자의 결과 파일과 Instructor Studio 과정 데이터는 수정하지 마.
```

## 사람이 확인할 인계 기준

원문 사실과 학습자 가정이 분리됐는지, 목표가 팀 결정과 일치하는지, 근거 위치를 다시 열 수 있는지 확인한 뒤 2번에게 넘긴다. `결과/01_근거와_목표.md`가 없으면 이 역할은 **미실행**이다.
