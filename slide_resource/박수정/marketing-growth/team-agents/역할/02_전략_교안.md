# 2번 에이전트 · 전략 연결과 교안 초안

**사용 시점:** 팀 결정이 [공유 브리프](../공유_브리프.md)에 반영되고 1번의 `01_근거와_목표.md`를 사람이 확인한 뒤. 회의 준비 완료 기준은 전략·커리큘럼 연결까지이며, 아래 **10분 시강 교안 제작은 회의 이후 작업**이다.

아래는 **재현용 지시문**이며 실행 기록이 아니다. [공용 `lesson-author` 스킬](../../tooling/lesson-author/SKILL.md)의 산출물 계약을 사용한다. 기존 [M1-1-P 60분 교안 초안](../../lesson-drafts/M1-1-P/lesson.md)은 별도 과정 차시이며 팀의 10분 시강 교안으로 간주하지 않는다.

## 전달할 지시문

```text
저장소 루트에서 작업해. .Codex/constitution.md,
marketing-growth/AGENTS.md, agents/lesson-author/SKILL.md,
agents/lesson-author/references/artifact-contract.md를 먼저 읽어.

너는 팀 과제의 2번 담당이다. 다음 입력을 확인해:
- marketing-growth/team-agents/공유_브리프.md
- marketing-growth/team-agents/결과/01_근거와_목표.md
- marketing-growth/과정_기획서.md
- marketing-growth/교과_차시_편성.md
- marketing-growth/evidence/근거_목록.md
- 이번 시강에 실제로 사용할 원문·가상 데이터 파일

1번 결과나 팀의 세부 주제·학습자·시강 시간이 없으면 교안을 추측해 쓰지 말고
누락된 입력을 보고해. 입력이 갖춰지면
marketing-growth/team-agents/결과/02_설계_요약.md에
'학습 요구 → 행동 목표 → 확인 증거 → 활동 → 필요한 설명'의 선택 이유와
112시간 과정의 교과·목차 중 이번 시강의 위치를 적어.

이어서 marketing-growth/team-agents/결과/02_교안/에
lesson.json, evidence.md, lesson.md, practice.md, review.md를 작성해.
lesson.json은 status=draft로 두고 구간 시간의 합을 팀이 확인한 시강 시간에 맞춰.
학생이 직접 수행할 행동과 결과 확인 구간을 포함하고 강사용 해설은 학생용
practice.md와 분리해. 가상 데이터는 실측으로, 관찰 차이는 인과 효과로 쓰지 마.
출처의 파일 경로와 쪽·절을 적고, 확인하지 못한 도구 화면·수치는 review.md에 남겨.

node agents/lesson-author/scripts/validate.mjs marketing-growth/team-agents/결과/02_교안
을 실행해 구조 오류를 고치고 검사 결과를 review.md에 기록해.
이 초안을 Instructor Studio 과정 데이터에 저장하거나 확정하지 마.
다른 담당자의 결과 파일은 수정하지 마.
```

## 사람이 확인할 인계 기준

팀이 정한 시강 시간, 목표와 학생 행동, 출처, 실습 재현성과 대체 시연을 검토한 뒤 3번에게 넘긴다. 구조 검사 통과만으로 강사 검토가 끝났다고 표시하지 않는다. `결과/02_설계_요약.md`와 교안 5개 파일이 없으면 **미실행**이다.
