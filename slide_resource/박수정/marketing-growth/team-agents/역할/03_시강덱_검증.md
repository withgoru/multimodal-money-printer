# 3번 에이전트 · 시강덱과 발표 근거 검증

**사용 시점:** 1번·2번 결과와 교안에 대한 사람의 인계 검토가 끝난 뒤. 이 역할은 회의 준비 완료의 조건이 아니라 **회의 이후 시강·발표 제작 단계**다.

아래는 **재현용 지시문**이며 실제 실행 기록이 아니다. 슬라이드는 이 프로젝트의 [기본 디자인 템플릿](../../tooling/slides-template/README.md)을 따른다. 기존 AI 답변 예시 발표덱은 이번 마케팅 시강의 결과로 표시하지 않는다.

## 전달할 지시문

```text
저장소 루트에서 작업해. .Codex/constitution.md,
marketing-growth/AGENTS.md,
output/course/curriculum-design/slides-template/README.md를 먼저 읽어.

너는 팀 과제의 3번 담당이다. 다음 결과를 확인해:
- marketing-growth/team-agents/공유_브리프.md
- marketing-growth/team-agents/결과/01_근거와_목표.md
- marketing-growth/team-agents/결과/02_설계_요약.md
- marketing-growth/team-agents/결과/02_교안/의 lesson.json, evidence.md,
  lesson.md, practice.md, review.md

앞 단계의 결과와 사람의 인계 확인이 없으면 시강이 완료된 것처럼 만들지 말고
누락된 입력을 보고해. 입력이 갖춰지면 기본 템플릿의 색상·글꼴·레이아웃으로
학생 목표, 짧은 설명, 한 번의 시연, 학생 행동과 결과 확인을 담은 시강 자료를 만들어.

출력은 marketing-growth/team-agents/결과/의
03_시강.html, 03_시강.pdf, 03_검토.md, 03_발표_근거.md다.
HTML 방향키·버튼 이동을 확인하고 PDF의 페이지 수, 글자 잘림, 출처 표시를
검토해. lesson.json의 시간표와 슬라이드 흐름을 대조해.

03_검토.md에는 실제로 열어 본 파일과 확인 결과, 남은 질문을 적어.
리허설을 하지 않았다면 소요 시간을 '미실행'으로 표시해.
03_발표_근거.md에는 '실제 제안 → 수강생 문제·학습 요구 → 전략·커리큘럼
→ 교안 → 스킬 → 사람이 고친 내용'의 각 주장과 실제 증거 파일을 연결해.
없는 결과나 확인하지 않은 사실을 완료로 표시하지 마.
다른 담당자의 결과 파일과 Instructor Studio 과정 데이터는 수정하지 마.
```

## 사람이 확인할 인계 기준

세 사람이 HTML·PDF의 내용과 출처를 보고, 실제 시강 리허설 시간과 학생 행동을 확인한다. 이 기록이 없으면 `03_시강.*` 파일이 존재해도 **발표 검증 완료로 표시하지 않는다**.
