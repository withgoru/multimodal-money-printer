# 팀 에이전트 작업 목차

과정과 팀의 현재 완료 범위는 [단계별 산출물 지도](../진행_현황.md)에서 확인한다. 팀이 함께 결정할 입력은 [공유 브리프](./공유_브리프.md)에 둔다.

## 작업 파일

| 용도 | 파일 |
|---|---|
| 현재 공통 입력과 미결정 사항 | [공유 브리프](./공유_브리프.md) |
| 회의 준비 자료 | [과정 기획서](../과정_기획서.md) · [교과·차시 편성](../교과_차시_편성.md) · [공유 브리프](./공유_브리프.md) |
| 파일 소유권과 인계 기준 | [과정별 에이전트 지침](../AGENTS.md#팀-공동-작업과-인계) · [실행 순서](./실행_순서.md) |
| 각자의 실행 지시문 | [1번 제안·학습 요구](./역할/01_제안_학습요구.md) · [2번 설계·교안](./역할/02_전략_교안.md) · [3번 덱·검증](./역할/03_시강덱_검증.md) |

`역할/`의 세 문서는 회의 이후 복사해 사용할 **재현용 지시문**이다. 실제 명령 실행 이력은 아니다. `결과/`는 세 담당자의 실행 산출물을 모으는 위치이며 현재는 `.gitkeep`만 있다. 예정 파일과 인계 기준은 [과정별 에이전트 지침](../AGENTS.md#팀-공동-작업과-인계)에 있다.
