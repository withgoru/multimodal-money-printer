# 멀티모달 AI 데이터 기반그로스 마케팅 · 5단계 파일 기반 편성 초안

작성일: 2026-11-18<br>
상태: **파일 초안 작성 · Instructor Studio S2~S4 저장 완료**. [적용·검증 기록](./LMS_적용_기록_2026-11-18.md)에 과정 ID, 목차 분리 방식과 남은 작업을 기록했다.

## 편성 기준

[과정 기획서](./과정_기획서.md)의 **112시간 독립 과정** 결정, 목표 직무, 최종 프로젝트와 [채택 커리큘럼·NCS 선정 기록](./NCS_선정_기록.md)을 입력으로 사용한다. 이 파일은 5단계의 **교과 시간 → 교안 목차 → 자료 재사용·신규 제작 판단**을 순서대로 기록한다. 아래 교과·차시별 시간은 REF-031의 원문 시간이 아닌 이 과정의 검토용 설계값이다.

최종 과제는 하나의 **가상 또는 사용 허가를 받은 캠페인의 다음 집행안**을 제안하는 것이다. 학습자는 측정 계획, 데이터 품질 기록, GA4 분석·대시보드, 멀티모달 소재 검토와 A/B 실험 해석, 예측·시뮬레이션, 실행·예산안을 묶어 제출한다. 프로젝트 제작·발표 시간은 아래 교과의 실습 시간에 포함하며 별도로 더하지 않는다.

## 1. 교과 시간과 평가 증거

운영 순서는 **성과 기준 → 분석 도구 → 고객데이터 → 실험 → 예측 → 전략 제안**이다. 사용자가 채택한 7개 주제의 문구는 바꾸지 않고, 선수 관계에 따라 6개 교과에 배치했다. 각 NCS 교과는 [선정한 능력단위](./NCS_선정_기록.md#2-선택한-ncs-능력단위) 하나에 대응한다. GA4·Looker Studio·AI 제품 기능과 실험 자동화·예측 모델은 비 NCS 시간에 편성한다.

M2에서는 GA4·Looker Studio의 **도구 조작**을 배우고, M1·M3에서는 그 도구로 NCS 과업의 성과 분석·데이터 해석을 수행한다. 같은 실습 시간을 두 교과에 중복 계상하지 않는다. 최초 편성 때 없던 [합성 고객 이벤트 R5](./evidence/112h-workbook/가상_데이터_설명.md)가 마련됐다. 실제 GA4 속성의 조작·권한 검증과 학생용 실습서 제작은 별도 작업이다.

## 3. 신규 제작·운영 조건

| 필요한 것 | 연결 항목 | 제작·확인 기준 |
