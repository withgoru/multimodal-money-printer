# M1-1-T · 강사 검토 기록

**상태:** 출처와 시간표를 연결한 이론 차시 초안. Instructor Studio S6에 저장하거나 강의 확정본으로 적용하지 않았다.

## 확인한 내용

- [편성표](../../교과_차시_편성.md)의 M1-1 이론 3시간에 맞춰 15+25+25+25+25+20+25+20 = **180분**으로 구성했다. 별도의 M1-1-P 실습 60분을 포함하지 않는다.
- NCS `0201030118_21v4`의 물리적 PDF 73쪽에서 수행준거 1.1~1.2를 확인했다. 특정 KPI·3시간은 과정 설계값이다.
- R1은 28개 데이터 행의 `synthetic` 자료다. 신규 고객·상품 보기·장바구니·환불 필드는 없으므로 이를 학생에게 자료 없음으로 표시하게 했다.
- Google Analytics의 key event 공식 설명과 Gordon 외 저자 원고의 관찰·실험 비교를 확인했다. 화면 조작이나 R1의 증분 효과를 확인한 것은 아니다.
- 강사용 설명·답안 단서는 `lesson.md`에, 학생 작성 양식은 `practice.md`에 분리했다.

## 가정과 사용 전 결정

1. 학습자는 광고·퍼널 용어와 스프레드시트 기초를 안다고 가정했다. 개강 전 진단 결과에 따라 도입 설명과 질문의 난도를 조정한다.
2. 180분의 실제 소요 시간과 25분 활동지 작성 가능 여부는 강사 시범 진행으로 확인한다. 휴식 시간 포함 방식도 기관 일정에 맞춰 결정한다.
3. R1의 교육용 브랜드·수치는 실제 광고 성과가 아니다. 기관이 실제 계정 실습을 원하면 데이터 사용 허가·GA4 권한·제품 화면을 별도로 검증한다.
4. NCS 사전·사후 평가 배점과 통과 기준은 S7에서 정한다. 이 차시의 질문은 형성 확인이며 정식 채점표가 아니다.
5. Instructor Studio의 통합 PDF 근거 색인에 누락 오류가 확인됐다. 이번 초안은 확인한 로컬 원문과 공식 문서 링크를 사용했으며, Studio 적용 전 자료실 색인과 원문 연결을 다시 검증한다.

## 제작·검증 기록

- `node agents/lesson-author/scripts/validate.mjs marketing-growth/lesson-drafts/M1-1-T --with-slides`: **통과**. 180분·출처 6개·수업 구간 8개, HTML·PDF 파일 형식 확인.
- HTML은 브라우저에서 `#2`로 열어 2/14 이동 상태를 확인했다. PDF는 **16:9, 14쪽**이며 전 페이지 렌더링에서 페이지 순서·본문·출처와 글자 잘림을 확인했다. 6쪽 수정 후 해당 쪽을 다시 렌더링했다.
- 출처의 수업 적합성·학생 수준·실제 소요 시간: 강사 검토 전.
