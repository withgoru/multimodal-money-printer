# M1-1-T · 근거와 확인 범위

이 차시의 180분은 [편성표의 M1-1](../../교과_차시_편성.md) 이론 3시간이다. 이어지는 60분 실습 M1-1-P와 시간을 중복 계상하지 않는다. 아래 ID는 [시간표](lesson.json)의 출처와 일치한다.

| ID | 확인한 위치 | 수업에 사용할 내용 | 해석 경계 |
|---|---|---|---|
| S1 | [교과·차시 편성](../../교과_차시_편성.md), `2. 교안 목차와 자료 판단` M1-1 행 | 광고 목표·전환 퍼널·KPI 정의, 이론 3시간과 실습 1시간 | 3시간은 이 과정의 설계값이며 NCS 공식 시수가 아니다. |
| S2 | [112시간 워크북](../../evidence/112h-workbook/112시간_실습_워크북.md), `M1-1. 광고 목표·전환 퍼널·KPI 정의` | 목표를 기간·대상·행동으로 쓰고 R1의 보유·누락 필드를 구분한다. | 워크북은 강사 검토용 원고다. 180분 수업의 실제 소요 시간을 검증하지 않는다. |
| S3 | [R1 CSV](../../evidence/multimodal-assets/daily_campaign_metrics.csv), 헤더·28개 데이터 행·`data_status` | 한 행은 날짜×캠페인이다. 노출·클릭·광고비·구매·매출이 있고 모든 행은 `synthetic`이다. | 상품 보기·장바구니·신규 고객 여부·환불 필드는 없다. 관찰값을 실측·무작위 실험으로 소개하지 않는다. |
| S4 | [NCS 마케팅전략기획 PDF](../../references/NCS.md), 물리적 73쪽 | `0201030118_21v4`의 1.1은 목표에 맞는 지표 선정, 1.2는 선정 지표에 따른 성과 관리 계획이다. | NCS가 CTR·GA4·루미 사례·3시간을 지정한 것은 아니다. |
| S5 | [Google Analytics Help · About key events](https://support.google.com/analytics/answer/9267568?hl=en), `What is a key event?`·`Report on key events` | 중요한 행동의 이벤트를 key event로 지정하고 보고서에서 발생 수와 귀속된 접점을 볼 수 있다. | 2026-11-18 원문 확인. 계정·현재 UI 조작은 확인하지 않았다. 발생 수나 귀속 수는 광고의 순수 증분 효과가 아니다. |
| S6 | [Gordon 외 저자 원고](https://www.kellogg.northwestern.edu/faculty/gordon_b/files/fb_comparison.pdf), 물리적 PDF 1쪽 초록·42~43쪽 결론 | 연구는 15건의 Facebook 광고 실험에서 관찰 기반 추정과 무작위 실험 결과가 자주 달랐다고 보고한다. | 저장본은 2018년 저자 원고다. 수업의 R1 값이나 모든 광고 채널에 연구 결과를 일반화하지 않는다. |

**설계 연결:** 사업 결과·행동·경로·보호 지표의 계층과 활동지 양식은 [근거 중심 학습서 1.1~1.2](../../evidence/근거_중심_학습서.md)의 교육용 설명을 바탕으로 이 차시에 맞게 재구성했다. 성취 여부와 학생 수준은 강사가 확인한다.
