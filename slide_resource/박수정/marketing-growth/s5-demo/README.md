# 멀티모달 AI 데이터 기반그로스 마케팅 · S5 강사 데모

교육용 합성 자료 R4와 R6으로 **성과표 구축 → 가상 실험 검산 자동화 → 읽기 전용 보고서 제공**을 보여 주는 강사용 작업 공간이다. [S5 실습 설계](../실습_데모_설계.md)의 3단계 데모를 재현한다. 학생은 코드를 복제하는 대신 지표 정의·검산·해석·제안 과제를 수행한다.

## 실행

Node.js가 있는 환경에서 이 폴더를 기준으로 실행한다. 외부 패키지·API 키는 필요 없다.

```sh
npm run build
npm start
```

`http://127.0.0.1:4173/`에서 보고서를, `/audit.json`에서 실험 검산 기록을, `/health`에서 로컬 상태를 확인한다. 포트를 바꿀 때는 `PORT`, 바인딩 주소를 바꿀 때는 `HOST` 환경변수를 사용한다. `dist/`는 재생성 산출물이라 Git에서 제외한다.

아래 Git 기준점은 원래 KDT 저장소의 작업 이력이다. 이 독립 저장소에는 해당 커밋이 없으며, 현재 파일의 재현 명령으로 각 단계를 확인할 수 있다.

| 단계 | 원래 KDT Git 기준점 | 재현 명령과 종료 증거 |
|---|---|---|
| build | `22e83ac` | `node build.mjs` → R4 504행의 채널×소재 6개 성과표. 관찰값과 실험 효과를 구분한다. |
| automate | `38164e0` | `node audit.mjs` → R6 16,000명의 배정·구매율·95% 단순 구간과 가상 AI 주장 검토표. 실제 AI 호출은 하지 않는다. |
| deploy 준비 | `e443be9` | `npm run build`와 `npm start` → 로컬 보고서·검산 JSON·상태 확인. 실제 클라우드 공개와 URL 검증은 아직 수행하지 않았다. |

## 데이터와 해석 경계

- `data/campaign_84d.csv`는 R4의 별도 관찰 사례다. 날짜·채널·소재별 합계에서 CTR·CPA·ROAS를 다시 계산한다. 전후 차이를 광고의 증분 효과로 표시하지 않는다.
- `data/controlled_copy_experiment.csv`는 R6의 **독립된 가상 무작위 배정 사례**다. 대조군 320/8,000명과 처리군 384/8,000명은 실제 플랫폼 결과가 아니다. 광고비·매출·환불이 없어 ROAS나 순이익을 계산할 수 없다.
- 가상 AI 주장 3개는 검토 절차 시연용 문장이다. 모델을 호출한 결과가 아니다. 실제 고객 식별자나 비밀 값은 넣지 않는다.
- 이 로컬 HTTP 서버는 교실 안의 재현 경로다. 공개 URL·클라우드 권한·배포 서비스 상태를 확인하기 전에는 실제 배포 완료로 표시하지 않는다.

## 강사 점검

1. `npm run build` 결과에서 R4 504행·6개 집계, R6 16,000명·대조/처리 8,000명씩을 확인한다.
2. 보고서의 주요 숫자 하나를 원본 CSV에서 재계산하고, R4와 R6이 서로 다른 사례라는 문구를 확인한다.
3. `/health`와 `/audit.json` 응답을 확인한다. 네트워크나 서버가 안 되면 `dist/report.html`을 직접 열고 `dist/audit.json`을 읽는다.
4. 실제 클라우드 공개는 플랫폼·계정·비용·공개 범위 결정 후 별도 실행하고 URL·배포 커밋·접근 결과를 기록한다.
