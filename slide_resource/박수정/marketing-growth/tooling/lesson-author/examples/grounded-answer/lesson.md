# 강사용 교안: AI 답변의 근거 확인하기

**대상:** AI 답변 검토를 처음 배우는 학습자  
**시간:** 10분  
**목표:** 두 답변 중 근거가 없는 답변을 찾아 원문과 비교해 설명한다.  
**준비:** `source.md`를 화면에 열거나 인쇄한다. 계정, API 키, 네트워크는 필요하지 않다.

| 시간 | 강사가 할 일 | 학생이 할 일 | 바로 확인할 것 |
|---:|---|---|---|
| 0–2분 | “AI 답변이 그럴듯해도 원문과 맞는지 확인합니다”라고 목표를 말한다. | 안내문과 두 답변을 읽는다. | 근거가 어디에 있는지 말한다. |
| 2–5분 | 답변 A를 원문의 「신청 취소」와 문장별로 대조해 보인다. | 일치하는 구절을 표시한다. | 답변 A의 출처 문장을 찾는다. |
| 5–8분 | 답변 B의 “30일” 주장에 출처가 있는지 묻는다. | 원문을 다시 읽고 근거 유무를 기록한다. | 원문에 30일 규정이 없음을 표시한다. |
| 8–10분 | “어느 답변을 수정해야 하나요? 왜인가요?”라고 묻고 정리한다. | 답변 B와 이유를 한 문장으로 말한다. | 원문은 첫 수업 전 취소만 말한다고 설명한다. |

**시연 실패 대안:** 화면 공유가 안 되면 `source.md` 인쇄물이나 이 파일의 문장을 읽어 비교한다.

**근거:** [수업용 가상 안내문](source.md). 실제 기관 규정으로 사용하지 않는다.
