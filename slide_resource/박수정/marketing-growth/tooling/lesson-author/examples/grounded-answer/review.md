# 검토 기록

- 구조 검증: `node scripts/validate.mjs examples/grounded-answer` 실행 대상으로 작성.
- 시간: 2 + 3 + 3 + 2 = 10분.
- 근거: 모든 사례 문장은 `source.md`의 가상 안내문에서 확인 가능.
- 환경: API 키·계정·네트워크가 없어도 인쇄물로 시연 가능.
- 강사 확인: 실제 학습자의 읽기 속도에 맞춰 3분 실습 시간이 충분한지 리허설 필요.
- 상태: 강사 검토용 초안. 과정 데이터에 저장하거나 확정하지 않음.
