# 교안 제작 모듈

## 입력 정리

주제, 학습자, 수업 시간, 관찰할 수 있는 학생 행동 한 가지, 실습 환경과 제약을 기록한다. 과정 전체의 목표와 한 차시의 목표를 구분한다. 10분 시강에는 과정 전체의 성과 대신 그 시간에 확인할 수 있는 행동 한 가지를 둔다.

## 근거 확인

제공된 원문과 기존 과정 자료를 읽고, `lesson.json`의 출처 ID와 일치하는 근거 목록을 작성한다. 각 항목에 파일 경로 또는 URL, 절·쪽·제목 같은 위치, 수업에 사용할 사실, 불확실한 부분을 적는다. 읽지 못한 자료는 확인 필요로 기록하고 원문을 확인한 것처럼 인용하지 않는다. KDT 작업에서 NCS 능력단위나 수행준거를 언급할 때는 해당 원문과 위치를 연결한다.

## 차시 설계

학생에게서 관찰할 결과를 먼저 정한다. 그 결과의 확인 방법, 결과를 만드는 활동, 필요한 최소한의 설명 순으로 설계한다. `lesson.json`에 수업 구간을 진행 순서대로 적고, 각 구간에 강사 행동·학생 행동·확인할 결과·사실 주장에 연결된 출처 ID를 기록한다. 구간별 시간의 합은 `durationMinutes`와 같아야 한다.

## 교안 작성

`lesson.md`에는 강사용 준비 사항, 시간별 진행, 말하거나 보여 줄 내용, 예상 학생 반응, 시연 실패 시 대체 방법을 적는다. `practice.md`에는 학생 과제, 시작 상태, 수행 단계, 기대 결과, 제출 증거를 적는다. 명령어·화면 명칭·배포 주소·계정의 동작을 실제로 확인하지 않았다면 확인된 것처럼 쓰지 않는다. 모르는 항목은 강사가 확인하도록 표시한다.

## 검토

`review.md`에 확인한 내용, 가정한 내용, 시간 합계, 근거가 부족한 내용, 사용 전에 강사가 결정할 항목을 적는다. 활동에 API 키·네트워크·유료 자원·실행 중인 서비스가 필요하면 실제로 사용할 수 있는 대체 방법을 제시한다. 강사 검토를 받을 준비가 되었는지 기록하되 과정 확정으로 표시하지 않는다.

## 추가 형식 출력

전체 교안 생성 요청에는 별도 형식 지시가 없어도 `lesson.html`, `lesson.pdf`를 만든다. PPTX·PowerPoint 형식을 명시적으로 요청받은 경우에만 `lesson.pptx`를 만든다. 사용자가 형식을 지정하면 그 지시를 따른다. 차시 설계나 부분 수정에는 필요할 때만 발표 자료를 만든다. 프로젝트 템플릿을 사용하고 강사용 원고를 그대로 붙여 넣는 대신 핵심만 담는다. 생성한 형식의 차시 내용과 순서를 맞추고 실제로 열어 눈으로 확인한다. 강사용 메모와 채점 해설은 학생용 자료에서 제외한다. PDF가 만들어졌다는 사실은 수업을 진행하거나 교안을 승인했다는 증거가 아니다.
