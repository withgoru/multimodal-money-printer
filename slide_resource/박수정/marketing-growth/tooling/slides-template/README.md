# STEP 03 스타일 슬라이드 템플릿

원래 KDT 작업 공간의 STEP 03 슬라이드에서 **디자인만** 분리한 재사용 템플릿입니다. 표지와 본문 슬라이드의 색상, GMarketSans 글꼴, 여백, 제목, 결과물 강조선, 페이지 번호를 포함합니다. 과정 내용은 들어 있지 않습니다.

이 프로젝트에서는 **“[주제] 슬라이드 만들어줘”**라고 요청하면 이 디자인을 기본으로 사용합니다. 예: “클라우드 비용 최적화 슬라이드 만들어줘”. 다른 디자인이나 PPTX·Google Slides 형식을 원하면 요청에 함께 적으면 됩니다.

## 사용 방법

1. 이 폴더 전체를 새 강의 폴더로 복사합니다. fonts 폴더까지 함께 복사해야 같은 글꼴이 표시됩니다.
2. template.html의 대괄호 자리표시자를 바꾸고, 본문 section을 복사해 장수를 늘립니다.
3. 브라우저에서 HTML을 열어 발표합니다. 방향키와 이전·다음 버튼으로 넘길 수 있습니다.
4. PDF가 필요하면 Chrome에서 인쇄할 때 **배경 그래픽**을 켜고 PDF로 저장합니다. 인쇄 크기는 16:9입니다.

template.css가 디자인을, template.js가 페이지 번호와 슬라이드 이동을 담당합니다. 본문은 한 장에 제목 1개, 짧은 설명 2개, 결과물 1개를 기준으로 설계했습니다.

이 템플릿은 HTML 슬라이드용입니다. PowerPoint에서 편집 가능한 PPTX 템플릿은 아직 포함하지 않습니다.
