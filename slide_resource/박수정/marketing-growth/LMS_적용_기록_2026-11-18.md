파일 초안의 **23개 활동**은 각 행에 이론·실습 시간이 모두 있어 Studio 목차 모델의 `theory`·`practice` 항목으로 분리했다. 결과는 **46개 목차 항목**이다. 각 항목의 메모에 파일 초안 ID, 학생 결과, 현재 실습 입력 파일과 조건을 기록하고 NCS PDF·REF-031·데이터 팩의 추출 위치 또는 외부 공식 문서 링크를 연결했다.

파일 초안의 6개 항목에서 재사용하는 R1~R3는 **가상 CSV·이미지·음성·영상의 실습 입력 파일**이다. Studio의 `reuse`는 기존 **수업 자료를 그대로 사용해 교안을 새로 만들지 않는 결정**이므로 의미가 다르다. 현재 완성된 학생용 교안·실습 지시서가 없어 Studio의 46개 목차는 모두 `new`로 저장하고, R1~R3의 기존 입력 파일 경로와 해석 한계를 메모·근거 위치에 남겼다. 수업 자료가 나중에 완성되면 항목별로 다시 `reuse`를 판단한다.

## 최초 적용 당시 검증과 남은 범위

Instructor Studio의 `get_course`에서 교과 **6개·112시간**, 목차 **46개·이론 38시간·실습 74시간**, 자료 결정 `new` **46개**를 다시 읽었다. `get_flow_status` 결과는 **S0 3/3, S1 7/7, S2 6/6, S3 6/6, S4 46/46 모두 `done`**이며 현재 단계는 **S5 실습·데모 설계**다.

revision 9 당시 `validate_course`에는 `PRACTICE_MISSING` 1건이 있었다. 이후 실습 23개와 강사 데모의 실제 Git 기준점이 연결돼 Studio 플로우는 **S5 26/26**으로 표시된다. 이는 로컬 데모 기준점의 충족이며 실제 클라우드 공개·광고 집행의 검증을 뜻하지 않는다. 교안 제작(S6), NCS 사전·사후 평가(S7), 실제 개강 일정에 따른 운영표(S8), 강사의 PDF 검토·최종 확정(S9)이 남아 있다. 현재 단계와 revision은 Studio에서 다시 조회한다. 이 기록은 **편성 S2~S4 최초 적용**의 근거이며, 전체 강의자료·훈련과정 확정의 근거는 아니다.
