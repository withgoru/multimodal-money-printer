# multimodal-money-printer

**멀티모달 AI 데이터 기반 그로스 마케팅** 강의의 설계 기록, 통합 과정기획서, 교안 및 팀 발표자료를 모아 두는 저장소입니다.

박수정 · 원성일 · 최우영 세 사람이 동일한 7줄 커리큘럼 주제를 각자의 방식으로 설계한 뒤, AI 3종(Claude · ChatGPT · Gemini)으로 교차 비교해 [통합 과정기획서(안)](slide_resource/결론_통합과정기획서.md)과 [팀 발표자료(22장)](lectures/90-팀발표.md)를 만들었습니다.

## 학습목표와 교과·14일 구성

### 학습목표 4개

1. **데이터 정합성 검증 및 퍼널 진단:** 광고 관리자(Meta·카카오)와 GA4 전환 수 차이를 집계 기간·정의·UTM·기여 기준으로 대조하고, 퍼널 이탈 구간에서 근거와 우선순위를 갖춘 개선안 3개를 도출한다.
2. **A/B 실험 설계 및 통계적 판정:** 표본 크기를 사전 계산해 단일 변수·대조군·동시 집행·수정 금지 원칙으로 클릭률(CTR) 중심 A/B 실험을 설계하고, p값과 표본 한계를 설명하며 도입·보류를 판정한다.
3. **멀티모달 AI 활용·검증 및 자동화 구축:** 멀티모달 AI의 소재 해석·변형 결과를 가설로 두고 성과 데이터로 검증하며, 이상값(0·급변) 발생 시 사람 확인 단계가 포함된 자동화 워크플로우를 구축한다.
4. **예측 시뮬레이션 및 최종 의사결정 제안:** 기여 모델별 ROAS 비교와 낙관·기준·비관 예산 시나리오를 산출하고, 가정 조건과 소규모 검증 실험 계획을 담은 최종 제안서를 3분 안에 발표한다.

## 교안 작성 및 발표 실행 (Slidev)

교안과 팀 발표 슬라이드는 [Slidev](https://sli.dev)로 만들고, 테마는 Apple Basic에 미니멀리즘을 덧씌워 씁니다.

| 역할 | 폰트 | 쓰는 곳 |
| --- | --- | --- |
| 제목 | IBM Plex Sans KR | 슬라이드·섹션 제목, 표 머리글 |
| 본문 | SUIT | 문단, 목록, 표 |
| 코드·강조 | Nanum Gothic Coding | 코드 블록, 인용문, 강조 블록 |

폰트는 npm 패키지로 번들되어 있어 외부 CDN 없이 동작합니다(교실 네트워크가 막혀 있어도 슬라이드가 열립니다).

```bash
npm install                                       # 처음 한 번
npm run sample                                    # 디자인 시스템 샘플 열기
npm run dev -- lectures/90-팀발표.md              # 팀 발표자료 열기
npm run build -- lectures/90-팀발표.md            # 팀 발표자료 정적 빌드(lectures/dist/)
npm run dev -- lectures/01-intro.md               # 회차별 교안 열기
npm run export -- lectures/01-intro.md            # PDF 내보내기(playwright-chromium 필요 가능, 미시험)
```

- Node.js 20.12 이상이 필요합니다.
- 새 교안은 `lectures/` 아래에 `NN-제목.md`로 추가하고, 머리말(frontmatter)은 [샘플](lectures/00-sample.md)을 복사해 시작합니다(`theme`, `fonts`, `colorSchema` 유지).
- 공통 스타일은 [index.css](lectures/styles/index.css), 강조 블록은 [Callout.vue](lectures/components/Callout.vue)(`<Callout title="핵심">내용</Callout>`)에 있습니다. `section`·`statement`·`fact` 레이아웃과 Mermaid `flowchart LR`(특수문자·괄호 포함 라벨은 큰따옴표로 감싸기)을 사용할 수 있습니다.
- 본문 큰 글씨·제목에서는 SUIT 글리프 문제로 `→`가 `>`처럼 보일 수 있으므로 말풀이나 Mermaid를 사용합니다.
- 슬라이드 파일은 `lectures/` 안에 있어야 공통 스타일과 컴포넌트가 적용됩니다.

## 자료를 올릴 때 지킬 것

- **API 키와 계정 정보는 커밋하지 않습니다.** Model API 키는 환경 변수(`MODEL_API_KEY`)로만 다루고, `.env` 파일은 `.gitignore`에 들어 있습니다.
- **소재 이미지는 강사 제작 또는 수강생 본인 소재만 올립니다.** 타사 광고와 인물 사진은 저작권과 초상권을 확인하기 전에는 올리지 않습니다.
- **수강생 개인정보와 팀 광고 계정 데이터는 올리지 않습니다.** 실습용 데이터는 익명화하거나 강사가 만든 샘플을 씁니다.
- **Muse Spark는 Standard 모드만 씁니다.** Contributor 모드는 입력 내용을 Meta 모델 학습에 쓰도록 허락해야 합니다.
